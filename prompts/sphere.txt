Add the Magic sphere from Sara Lobo Library to my app.

Install:
npm install craft-library

Usage (React 18+):
import { MagicSphere } from 'craft-library';

{isThinking && <MagicSphere />}   // isThinking: your own state, true while you wait for the answer

Plain HTML (no build step):
<script src="https://cdn.jsdelivr.net/npm/craft-library@0/dist/craft.js"></script>
<magic-sphere></magic-sphere>
<!-- show it while you wait and remove it when the answer arrives -->

Props (in HTML, attributes of the same names):
- label: the word beside the ball (default "Thinking"; "" shows the ball alone, still announced as "Thinking")
- size: the ball, px or any CSS length (default 32). Under 64px it draws finer, denser dots made to sit beside text; larger, it shows the full detail

A "thinking" indicator for AI replies: a ball of dots that works like a Rubik's cube, one grey tone per face. Its slices turn and scramble the pieces, then retrace their steps until every piece is home, and the ball lights up for a moment while a light passes through the word. Use it as it is, without restyling or rebuilding it, on a dark background (on a light one, set --thinking-ink and --thinking-dim on it).
Docs: https://www.npmjs.com/package/craft-library
